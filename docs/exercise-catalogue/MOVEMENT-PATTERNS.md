# Movement Patterns

Movement patterns are programming descriptors rather than exhaustive biomechanical diagnoses.

## Assignment

- Every candidate has one `primary_movement_pattern`.
- `secondary_movement_pattern` is optional and should be used only when a second pattern materially helps programming or substitution.
- Values come from `catalogue/reference/controlled-values.json`.
- Avoid encoding plane, stance, tempo, or equipment in the pattern field.
- Carries and locomotion use purpose-specific patterns instead of being forced into push/pull labels.
- Mobility candidates use `Mobility` when their principal purpose is accessible range or movement preparation.

The initial vocabulary includes horizontal and vertical push/pull, squat, hinge, lunge, locomotion, carry, rotation, anti-rotation, flexion, extension, lateral flexion, Olympic lift, loaded event, cyclical conditioning, and mobility. Changes require coaching review because movement labels affect search, substitutions, and reporting.
