# Integration Origin

This catalogue workspace was prepared as an external content-architecture deliverable, reviewed against the Android repository, and then integrated into the repository using repository-relative paths.

Repository placement:

- this documentation under `docs/exercise-catalogue/`;
- candidate and reference files under `catalogue/`;
- validator under `tools/catalogue/`;
- validator regression tests under `tests/`.

No application source, Room schema, Firestore mapping, seed records, Gradle configuration, or runtime behaviour is changed by these files.
